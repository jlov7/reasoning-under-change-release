# Support

Reasoning Under Change is maintained as personal R&D. There is no support SLA or
production-service commitment. The [stability policy](docs/STABILITY.md) defines
the supported V1 interface and platforms.

For a usage problem, start with `ruc-work --help`, [Usage](docs/USAGE.md) and the
README recovery table. Include package version (`ruc-work --version`), Python
version, the command, expected result and actual structured error/request ID.
A minimal synthetic queue and prior plan make a bug report reproducible. Check
whether the input still has the exact revision/content that produced the plan.

Use an issue in the repository for non-sensitive bugs and questions. Share only
inputs, estimates and files you have the right to disclose. Do not post customer
or employer information, credentials, full private backlogs or private logs.
For a suspected vulnerability, follow [Security](SECURITY.md).
